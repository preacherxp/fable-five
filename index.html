fable-five

Five projects written by Claude Fable 5.2 in one session. Each runs in the browser with no dependencies and no build step.

  1. Black holeA rotating (Kerr) black hole ray traced in a fragment shader. Every pixel integrates a photon geodesic.
  2. ccA C compiler with structs, pointers and doubles that writes WebAssembly bytes directly. It compiles a ray tracer.
  3. GPT in a tabA 4-layer transformer with backprop written by hand, training on all your CPU cores while you watch.
  4. Water, jelly and snow in 3DOne MLS-MPM solver for three materials that collide and mix.
  5. sqlA SQL engine with recursive CTEs, window functions, subqueries, B+tree indexes and a query plan.
